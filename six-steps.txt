# Steps to create and run the Inventory Management Project

### 1. Folder structure in VS Code

Inside your existing `Prog6` folder, create:

```
Prog6
│
├── client
│   └── src
│       ├── to_inventory.js
│       ├── index.js
│       └── index.css
│
└── server
    └── myinventory.js
```

### 2. Terminal 1 – Backend setup

Open Terminal 1 in VS Code.

```
cd server
npm init -y
npm install express cors
```

Create `myinventory.js` inside the `server` folder and paste the backend code.

To run the backend:

```
node myinventory.js
```

Expected: `Express is working at http://localhost:8000`

Keep this terminal running.

### 3. Terminal 2 – Frontend setup

Open a second terminal in VS Code.

If React is not already created, run from the `Prog6` folder:

```
npx create-react-app client
```

Then:

```
cd client
npm install axios
```

Inside `client/src`, create or edit these files:

| File              | Purpose                    |
| ----------------- | -------------------------- |
| `to_inventory.js` | React components and Axios |
| `index.js`        | Main entry point           |
| `index.css`       | Pastel CSS styling         |

Paste the respective frontend codes.

### 4. Run the frontend

In Terminal 2:

```
npm start
```

### 5. Final output

- Backend: `http://localhost:8000` – displays inventory JSON.
- Frontend: `http://localhost:3000` – displays inventory table and add-product form.

Both terminals must remain running

Note: Since you have already created `client` and `server`, don't run `create-react-app` or `npm init` again. Just install any missing packages and run the commands above.
